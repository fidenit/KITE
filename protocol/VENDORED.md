# A copy of PATET

This folder is a copy of [PATET](https://github.com/fidenit/patet), the protocol this app is built on, at commit `55471fb`.
Do not edit it here: change PATET, then copy it over again (`python tools/vendor_patet.py` with the PATET repository beside this one).
The app builds its Rust code from `rust/`, gives `GUIDE.md` to outside agents, and runs `conformance/` in its tests.
